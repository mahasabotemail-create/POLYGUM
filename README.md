## پنل مدیریتی پلی‌گام

پنل وب مینیمال راست‌چین برای شرکت پلی‌گام که فرآیند ثبت پروژه‌ها، یکپارچه‌سازی با n8n و ارسال داده به مغز فنی (OpenAI) را در یک فرم واحد مدیریت می‌کند. رابط کاربری به زبان فارسی و با تم صنعتی تیره طراحی شده است.

## امکانات اصلی

- 🎯 فرم یکپارچه ثبت پروژه و مشتری با پیام وضعیت لحظه‌ای
- 📦 ذخیره پروژه‌ها در SQLite (Prisma) به عنوان CRM داخلی
- 🔗 ارسال هم‌زمان داده‌ها به Webhook پلتفرم n8n
- 🧠 ارسال خلاصه فنی به OpenAI (مغز فنی پلی‌گام)
- 📋 صفحات تفکیک شده برای فرم، CRM، پروپوزال‌ها، داشبورد و تنظیمات
- 🎨 طراحی تاریک صنعتی (مشکی + زرد)، فونت فارسی Vazirmatn، راست‌چین کامل

## فناوری‌ها

- [Next.js 16](https://nextjs.org) (App Router)
- [Tailwind CSS 4](https://tailwindcss.com) با تم سفارشی
- [Prisma ORM](https://www.prisma.io) + SQLite
- TypeScript و ESLint

## راه‌اندازی

1. وابستگی‌ها را نصب کنید:

   ```bash
   npm install
   ```

2. فایل‌های محیطی را تنظیم کنید:

   ```bash
   cp .env.local.example .env.local
   ```

   سپس مقادیر زیر را در `.env.local` تکمیل کنید:

   ```env
   N8N_WEBHOOK_URL="https://n8n.example.com/webhook/poligam"
   POLIGAM_AI_KEY="sk-..."
   ```

   اتصال پایگاه داده از طریق فایل `.env` و مقدار پیش‌فرض زیر تنظیم شده است:

   ```env
   DATABASE_URL="file:./prisma/db.sqlite"
   ```

3. پایگاه داده را مهاجرت دهید (در اولین اجرا):

   ```bash
   npx prisma migrate dev
   ```

4. سرور توسعه را اجرا کنید:

   ```bash
   npm run dev
   ```

   پنل از طریق آدرس [http://localhost:3000](http://localhost:3000) در دسترس است.

## گردش ثبت پروژه

1. کاربر فرم صفحه اصلی (`/`) را تکمیل می‌کند.
2. داده‌ها در جدول `projects` ذخیره می‌شوند (وضعیت اولیه: `جدید`).
3. همان payload به Webhook n8n ارسال و پاسخ آن نمایش داده می‌شود.
4. خلاصه فنی برای مغز فنی پلی‌گام (OpenAI) ارسال و نتیجه آن گزارش می‌شود.
5. پیام سبز موفقیت یا هشدار قرمز خطا بسته به نتیجه هر اتصال نمایش داده می‌شود.

## صفحات

- `/` – فرم ثبت پروژه جدید + گزارش وضعیت ارسال
- `/crm` – لیست پروژه‌ها، جست‌وجو و وضعیت اتصال‌ها
- `/proposals` – مشاهده وضعیت پروپوزال‌های مرتبط
- `/dashboard` – نمای کلی آمار پروژه‌ها و توزیع
- `/settings` – ورود یا به‌روز‌رسانی Webhook n8n و کلید مغز فنی

## دستورات مفید

- `npm run dev` – اجرای محیط توسعه
- `npm run build` – ساخت نسخه تولید
- `npm run start` – اجرای نسخه تولید
- `npm run lint` – بررسی کد با ESLint
- `npx prisma studio` – مشاهده داده‌ها در رابط Prisma Studio

## نکات امنیتی

- کلیدهای حساس را فقط در `.env.local` نگهداری کنید؛ این فایل در git ذخیره نمی‌شود.
- برای محیط تولید، از مسیر امن HTTPS برای Webhook استفاده کنید.
- پاسخ‌های دریافتی از n8n و OpenAI در فرم به صورت خلاصه نمایش داده می‌شوند؛ در صورت نیاز به جزئیات بیشتر، از ابزارهای مانیتورینگ سرویس‌ها استفاده کنید.
